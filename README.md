# Tab Manager

A firefox addon to manage tabs.

## Status

This addon is in exploration stage. I'm getting familiar with the firefox addon api.

## Why

- To learn the firefox addon api by practicing.
- To have a better way to manage tabs. (OneTab is doing good in turn of functionality but it is slow when there are many tabs.)
